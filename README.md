# LIB_GAD

GAD = **Generic Any Data**, and our game **Genetic Anomaly Detector**. The reference is Ed
Zavada's Galactica-4 (MIT-licensed code); its source folder is git-ignored here, only the
notes and a sample save are tracked.

| File | What |
|---|---|
| `GAD_ESSENCE_AND_VARIABLES.md` | what Galactica is under the paint, and every variable Vibecode3D / xt3d must mirror |
| `GAD_SELF_WRITING_SCRIPTS.md` | code as data: the GAD stack that rewrites its own script (from the harvests) |
| `GENERICA_TEMPLATE.md` | Generica (the owner's property-set stacks) as the template for GAD data (TODO A-12) |
| ~~`Galactica Game.gad4.json`~~ | removed by the owner 17 Nov 2026. Its star names live on in `LIB_LISTS/Lists/Galactica_Star_Names.txt`. For Galactica 4-compatible output, take a fresh sample save from Ed Zavada's latest commits at that time, in case the format changes meanwhile |

## In this folder since 16 Nov 2026

- `GeneticAnomaly/`: the Genetic Anomaly Detector prototype, moved from LIB_GAMES (its home is here now)
- `ui/GenericaAnyData_04042018a/`: the 2018 Galactica 3-based GUI (XTJSON harvest), the base for GAD's own UI
